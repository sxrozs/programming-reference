## 📖 О проекте

**Complete Programming Reference** — наглядный справочник, в котором собраны теги, ключевые слова, свойства и функции 28 языков программирования с кратким объяснением назначения каждого.

Удобно для обучения, быстрого повторения и как шпаргалка под рукой. Доступен на английском и русском языках.

## 💻 Что внутри

**Web:** HTML · CSS · JavaScript · TypeScript · PHP · SQL  
**Системные:** C · C++ · C# · Go · Rust · Swift · Kotlin  
**Скрипты / Data:** Python · Ruby · R · Lua · Perl · MATLAB · Julia  
**Прочее:** Java · Dart · Scala · Haskell · Elixir · Groovy · Basic · Solidity

Для каждого языка — все основные теги / ключевые слова / функции и что они делают.
